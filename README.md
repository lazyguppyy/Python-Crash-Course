##Chapter 2: Variables and Simple Data Types
- a method is an action that Python can perform on a piece of data.
  - every method is followed by a set of parenthesis, because methods often need additional information to do their work. That information is provided inside the parenthesis. Due to no additional information needed, parenthesis are left empty.
  - string methods:
    - .title() - changes each word to title case
    - .upper() - changes each word to upper case
    - .lower() - changes each word to lower case
